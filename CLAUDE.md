# Algoritmia y Estructuras de Datos Avanzadas

Proyecto para construir el material completo de la asignatura (16 semanas, 2 sesiones de 1.5 h por semana).

- El programa oficial está en [PROGRAMA.md](PROGRAMA.md) y es la fuente de verdad: temas, orden, problemas asignados, evaluación y temas excluidos.
- Idioma del material: español.
- Lenguaje: Python 3 ejecutado siempre con PyPy, nunca con CPython: envíos, pruebas y mediciones se hacen con PyPy. Usar la plantilla base del curso (`input = sys.stdin.readline`, código dentro de `main()`, salida con `sys.stdout.write`).
- Priorizar DFS iterativo y DP bottom-up; no usar `sortedcontainers`.
- No incluir temas de la tabla de "Temas excluidos" salvo que se pida como extensión.
- Cada problema asignado debe tener una solución en Python que pase el límite de tiempo.
