# Algoritmia y Estructuras de Datos Avanzadas

Proyecto para construir el material completo de la asignatura (16 semanas, 2 sesiones de 1.5 h por semana).

- El programa oficial está en [PROGRAMA.md](PROGRAMA.md) y es la fuente de verdad: temas, orden, problemas asignados, evaluación y temas excluidos.
- Idioma del material: español.
- Lenguaje: Python 3 ejecutado siempre con PyPy, nunca con CPython: envíos, pruebas y mediciones se hacen con PyPy. En los ejemplos de código del material, usar entrada y salida normal (`input()` y `print()`) con el código dentro de `main()`. La lectura y escritura rápidas (`sys.stdin.readline`, `sys.stdout.write`) solo aparecen en el tema de la semana 4, donde se comparan las dos formas.
- Priorizar DFS iterativo y DP bottom-up; no usar `sortedcontainers`.
- No incluir temas de la tabla de "Temas excluidos" salvo que se pida como extensión.
- Cada problema asignado debe tener una solución en Python que pase el límite de tiempo.
- Las clases están en `docs/` (GitHub Pages). Qué clases pueden abrir los estudiantes se define en `docs/config.js` (`disponible: true/false`); una clase nueva también se agrega ahí para que aparezca en el índice.
