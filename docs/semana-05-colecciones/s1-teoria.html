Parte 1

Conjuntos: set

Valores sin repetir, con pertenencia en O(1).

set

Operaciones básicas de un set

s = set()              # vacío ({} es un dict)
s = {3, 1, 4}
s.add(5)               # O(1)
s.discard(9)           # borra si está; si no, nada
s.remove(9)            # KeyError si no está
4 in s                 # True, O(1) en promedio
len(s)

# sin repetidos
distintos = len(set(a))
ordenados = sorted(set(a))
# sin repetidos y en el orden de aparición
unicos = list(dict.fromkeys(a))

Un set guarda cada valor una sola vez. Si el valor ya está, add deja el set igual.

Sus elementos deben ser inmutables: enteros, strings o tuplas. Meter una lista en un set da TypeError.

Para guardar celdas de una grilla se usan tuplas: vis.add((i, j)).

Python no garantiza el orden en que se recorre un set. Si el orden importa, se usa sorted o dict.fromkeys.

El set usa una tabla hash, como se vio en la semana 2 con la búsqueda en lista frente a set. "O(1) en promedio" significa que una operación suelta puede tardar más, y que n operaciones tardan O(n) en total.

En PyPy 3.11 un set se recorre en orden de inserción. Es un detalle del intérprete: el lenguaje no lo garantiza.

Operaciones de conjuntos

Unión, intersección, diferencia y diferencia simétrica

  • A | B: está en A o en B.
  • A & B: está en los dos.
  • A - B: está en A y no en B.
  • A ^ B: está en uno solo.

Cada operación cuesta O(len(A) + len(B)).

Ejemplo de uso: los números que faltan de 1 a n son set(range(1, n + 1)) - set(a). Preguntar al grupo qué da A ^ B antes de presionar el botón.

Parte 2

Diccionarios: dict

De una clave a un valor: contar, agrupar y mapear.

dict

Operaciones básicas de un dict

d = {}
d["ana"] = 3            # crear o cambiar, O(1)
d["ana"]                # 3
d["eva"]                # KeyError: no existe
d.get("eva", 0)         # 0 si no existe
"eva" in d              # busca en las claves, O(1)
del d["ana"]

for k in d: ...             # claves
for k, v in d.items(): ...  # pares
for v in d.values(): ...    # valores

Las claves siguen las mismas reglas que los elementos de un set: no se repiten y deben ser inmutables.

Desde Python 3.7, un dict se recorre en el orden en que se insertaron las claves.

x in d busca entre las claves. Buscar un valor con x in d.values() es O(n).

Reemplaza a lista.index(x): con pos = {v: i for i, v in enumerate(a)} cada búsqueda de posición es O(1).

Contar

Contar apariciones con un dict

veces = {}
for w in palabras:
    veces[w] = veces.get(w, 0) + 1

Avanzar paso a paso. La primera vez que aparece una palabra se crea la clave (verde). Las siguientes veces se suma 1 (amarillo).

Counter y defaultdict

Cuatro formas de contar

from collections import Counter, defaultdict

# 1. get
d = {}
for x in a:
    d[x] = d.get(x, 0) + 1

# 2. if
d = {}
for x in a:
    if x in d:
        d[x] += 1
    else:
        d[x] = 1

# 3. una clave nueva empieza en int() = 0
d = defaultdict(int)
for x in a:
    d[x] += 1

# 4. Counter
c = Counter(a)

Con 10⁶ valores entre 1 y 1000, las cuatro tardaron entre 0.010 s y 0.012 s (PyPy 3.11, Apple M4). Se escoge la que se lea mejor.

c = Counter("abracadabra")
c["a"]              # 5
c["z"]              # 0, y la clave no se crea
c.most_common(2)    # [('a', 5), ('b', 2)]

Si los valores son enteros pequeños (por ejemplo, de 0 a 10⁶), una lista cnt = [0] * (m + 1) también sirve, como el arreglo de 26 letras de la semana 3.

Agrupar

Agrupar valores con defaultdict(list)

from collections import defaultdict

palabras = ["amor", "roma", "pato", "mora",
            "topa", "sol"]
grupos = defaultdict(list)
for w in palabras:
    clave = "".join(sorted(w))   # letras ordenadas
    grupos[clave].append(w)

for g in grupos.values():
    print(g)
['amor', 'roma', 'mora']
['pato', 'topa']
['sol']

Dos palabras son anagramas si tienen las mismas letras (semana 3). Al ordenar las letras, todos los anagramas dan la misma clave: "amor", "roma" y "mora" dan "amor".

defaultdict(list) crea una lista vacía la primera vez que se usa una clave. Sin él, habría que escribir if clave not in grupos: grupos[clave] = [].

Otro uso frecuente: las posiciones donde aparece cada valor, con pos[x].append(i).

Con defaultdict, leer grupos[k] crea la clave k con una lista vacía. Para preguntar si existe, usar k in grupos.

Solución · Codeforces 4C · Registration System

Un contador por nombre

Para cada nombre: OK si es nuevo. Si no, el nombre seguido del primer número libre.

def main():
    n = int(input())
    veces = {}
    res = []
    for _ in range(n):
        nombre = input()
        if nombre in veces:
            res.append(nombre + str(veces[nombre]))
            veces[nombre] += 1
        else:
            res.append("OK")
            veces[nombre] = 1
    print("\n".join(res))

main()

veces[nombre] es el número que le toca a la próxima repetición.

Las respuestas se juntan en una lista y se imprimen al final con un solo print.

Con 10⁵ solicitudes tardó 0.07 s con PyPy 3.11 en un Apple M4.

Caso que el enunciado permite y los casos de prueba no incluyen: "a", "a", "a1". La segunda solicitud registra "a1", así que la tercera debería responder "a11". Esta solución responde OK y es aceptada. Para cubrirlo, el nombre generado también se guarda en el dict.

Parte 3

Pilas

El último que entra es el primero que sale.

Pila con list

Una lista sirve como pila

pila = []
pila.append(x)    # apilar, O(1)
pila[-1]          # ver el tope
pila.pop()        # desapilar, O(1)
if pila:          # ¿hay elementos?
    ...

El tope de la pila es el final de la lista. append y pop() trabajan en el final, así que cuestan O(1).

pila.pop() y pila[-1] con la pila vacía dan IndexError. Antes de usarlos se revisa if pila.

10⁶ append seguidos de 10⁶ pop tardaron 0.005 s (PyPy 3.11, Apple M4).

Se usa una pila cuando lo que llegó al final es lo primero que hay que atender: cerrar el último paréntesis abierto o deshacer la última acción.

Paréntesis balanceados

Cada cierre debe coincidir con el último abierto

tope
pila
PAR = {")": "(", "]": "[", "}": "{"}

def balanceado(s):
    pila = []
    for c in s:
        if c in "([{":
            pila.append(c)
        elif not pila or pila.pop() != PAR[c]:
            return False
    return not pila

Probar con el ejemplo cargado: falla en el último ] porque el tope es (. Probar también (() (sobra un abierto, la pila no queda vacía) y ()) (llega un cierre con la pila vacía).

Evaluar expresiones

Expresión en notación posfija

pila = []
for tok in expr.split():
    if tok in ("+", "-", "*"):
        b = pila.pop()
        a = pila.pop()
        if tok == "+": pila.append(a + b)
        elif tok == "-": pila.append(a - b)
        else: pila.append(a * b)
    else:
        pila.append(int(tok))
print(pila[0])
tope
pila

En notación posfija el operador va después de sus dos operandos: 3 4 + es 3 + 4. La expresión del ejemplo es (3 + 4) · 2 − 7 = 7. No necesita paréntesis.

El orden de a y b importa en la resta: b es el que estaba en el tope. Una expresión normal, como (3 + 4) * 2, se puede pasar a posfija con otra pila; ese algoritmo no está en el programa.

Deshacer

Deshacer con una pila de acciones

Historial (el tope está a la derecha) 
texto = []
hist = []           # pila de acciones

def escribir(c):
    texto.append(c)
    hist.append(("escribir", c))

def borrar():
    if texto:
        hist.append(("borrar", texto.pop()))

def deshacer():
    if hist:
        op, c = hist.pop()
        if op == "escribir":
            texto.pop()
        else:
            texto.append(c)

Cada acción guarda lo necesario para revertirla. Deshacer saca la última acción y hace lo contrario. Aquí el texto también es una pila: se escribe y se borra al final.

Idea · Codeforces 26B

Regular Bracket Sequence

Pregunta para el grupo

Al recorrer la secuencia, ¿qué se hace con un ) que llega cuando no hay ningún ( abierto?

Se borra. Si hay un ( abierto, se cierra con él y se suman 2 a la respuesta.
Los ( que quedan abiertos al final también se borran.
Todos los elementos de la pila son (, así que basta un contador con su tamaño.

Solución · Codeforces 26B · Regular Bracket Sequence

Cerrar cada paréntesis con el último abierto

Hay que encontrar la secuencia correcta más larga que queda al borrar paréntesis.

def main():
    s = input()
    abiertos = 0
    largo = 0
    for c in s:
        if c == "(":
            abiertos += 1
        elif abiertos > 0:
            abiertos -= 1
            largo += 2
    print(largo)

main()

Una pasada, O(n). Con 10⁶ caracteres tardó 0.04 s (PyPy 3.11, Apple M4).

En verde los pares que quedan; en rojo los que se borran. La visualización empareja cada ) con su (. El código solo cuenta los ( abiertos.

Parte 4

Colas con deque

El primero que entra es el primero que sale.

deque

Operaciones en los dos extremos

from collections import deque

q = deque([1, 2, 3])
q.append(x)        # al final
q.popleft()        # saca el primero
q.appendleft(x)    # al inicio
q.pop()            # saca el último
q[0], q[-1]        # ver los extremos
q.rotate(k)        # mueve k a la derecha

Las operaciones en los extremos cuestan O(1). Acceder a q[i] en el medio cuesta O(n).

Una cola usa append y popleft. rotate(1) pasa el último al inicio; rotate(-1) pasa el primero al final. rotate(k) cuesta O(k).

Simulación

Una fila de atención por turnos

Cada cliente tiene varios trámites. La ventanilla atiende un trámite por minuto. Si al cliente le quedan trámites, vuelve al final de la fila.

q = deque([("A", 3), ("B", 1), ("C", 2)])
t = 0
while q:
    nombre, k = q.popleft()
    t += 1
    if k > 1:
        q.append((nombre, k - 1))
    else:
        print(nombre, "termina en", t)

Salida: B termina en 2, C en 5 y A en 6. La misma idea se usa en BFS (semana 12), donde la cola guarda los nodos por visitar.

Solución · CSES 2162 · Josephus Problem I

Saltar uno y sacar el siguiente

n niños en círculo. Se salta uno y se saca el siguiente, hasta que no queda nadie.

from collections import deque

def main():
    n = int(input())
    q = deque(range(1, n + 1))
    orden = []
    while q:
        q.rotate(-1)               # se salta
        orden.append(q.popleft())  # sale
    print(" ".join(map(str, orden)))

main()

El primero de la fila (amarillo) es el que se salta o sale en ese paso. Mostrar con n = 7 que la salida coincide con el ejemplo.

Con una lista, sacar un elemento del inicio o del medio mueve todos los que están después. Son O(n) por paso y O(n²) en total.

Resumen

Reglas para elegir la estructura

  1. Identificar la operación que se repite n veces.
  2. Para preguntar si un valor está, usar set.
  3. Para contar o agrupar, usar dict, Counter o defaultdict.
  4. Para atender lo último que llegó, usar una lista como pila.
  5. Para atender lo primero que llegó, usar deque con popleft.
