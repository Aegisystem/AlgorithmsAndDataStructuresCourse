Parte 1

Vocabulario

Nodos unidos por aristas.

Grafos

Un grafo tiene nodos y aristas

Nodo (o vértice): un elemento, como una ciudad. Arista: una conexión entre dos nodos, como una carretera.

Grado: cantidad de aristas de un nodo. Camino: secuencia de nodos unidos por aristas. Ciclo: camino que vuelve al nodo inicial sin repetir aristas.

Conexo: hay camino entre cualquier par de nodos. Árbol: grafo conexo sin ciclos; con n nodos tiene n − 1 aristas.

Usar los botones para marcar cada concepto en el grafo. Este grafo tiene n = 8 nodos y m = 9 aristas. En los enunciados, n suele ser la cantidad de nodos y m la de aristas.

Tipos de grafo

Dirigidos y ponderados

Dirigido: cada arista tiene sentido. a → b no permite ir de b a a. Ejemplo: el curso 1 es requisito del curso 2.

Ponderado: cada arista tiene un peso, como la longitud de una carretera. El camino más corto ya no es el de menos aristas.

En el grafo ponderado, de 1 a 4 el camino directo pesa 9 y el camino 1, 2, 3, 4 pesa 2 + 3 + 1 = 6. Los grafos ponderados se ven en la semana 13 con Dijkstra.

Parte 2

Representaciones

Cómo guardar un grafo en Python.

Representaciones

El mismo grafo de tres formas

aristas = [(1, 2), (1, 3),
  (2, 3), (3, 4)]

Lista de adyacencia

adj[1] = [2, 3]
adj[2] = [1, 3]
adj[3] = [1, 2, 4]
adj[4] = [3]

Para cada nodo, la lista de sus vecinos. Es la que más se usa.

Matriz de adyacencia

M[a][b] = 1 si hay arista. Ocupa n² casillas.

La lista de aristas es la forma en que llega la entrada. Se usa tal cual en Kruskal (semana 13). En un grafo no dirigido, cada arista aparece en la lista de adyacencia de sus dos extremos, y la matriz es simétrica.

Leer un grafo

Lista de adyacencia en Python

n, m = map(int, input().split())
adj = [[] for _ in range(n + 1)]   # nodos 1..n
for _ in range(m):
    a, b = map(int, input().split())
    adj[a].append(b)
    adj[b].append(a)      # quitar si es dirigido

# ponderado: guardar (vecino, peso)
#   adj[a].append((b, c))

Con n = 10⁵ la matriz tendría 10¹⁰ casillas, así que se usa la lista. La matriz sirve con n ≤ 1000 más o menos.

Se crea con n + 1 listas para usar los números de nodo del enunciado (1 a n) sin restar 1. Igual que con las matrices de la semana 4, [[]] * (n + 1) crearía n + 1 referencias a la misma lista.

Parte 3

DFS

Recorrer todo lo que se alcanza desde un nodo.

DFS iterativo

Recorrido en profundidad con una pila

visto = [False] * (n + 1)
visto[s] = True
pila = [s]
while pila:
    u = pila.pop()
    for v in adj[u]:
        if not visto[v]:
            visto[v] = True
            pila.append(v)

Cada nodo entra una vez a la pila y cada arista se revisa dos veces (una por extremo). Es O(n + m).

Avanzar paso a paso desde el nodo 1. En azul: nodos marcados que esperan en la pila. En amarillo: el nodo que se saca. En verde: nodos ya procesados. Se marca al meter en la pila para que ningún nodo entre dos veces. Este recorrido visita los mismos nodos que un DFS recursivo, pero no siempre en el mismo orden. Para componentes y flood fill el orden no importa.

DFS en Python

Por qué una pila y no recursión

# recursivo: profundidad hasta n
def dfs(u):
    visto[u] = True
    for v in adj[u]:
        if not visto[v]:
            dfs(v)

En un grafo que es un camino 1 – 2 – … – n, la versión recursiva hace n llamadas anidadas. Con n = 10⁵ eso es 10⁵ de profundidad.

En la semana 11 PyPy falló antes de 1.2·10⁴ llamadas anidadas, aun con sys.setrecursionlimit(10**6).

La versión con una lista como pila no tiene ese límite: la lista crece en la memoria normal del programa.

Con grafos pequeños, por ejemplo n ≤ 1000, la versión recursiva funciona. En el curso se usa siempre la iterativa para no depender del tamaño de la pila del juez.

Componentes conexas

Un DFS desde cada nodo sin visitar

visto = [False] * (n + 1)
comp = 0
for s in range(1, n + 1):
    if visto[s]:
        continue
    comp += 1          # componente nueva
    visto[s] = True
    pila = [s]
    while pila:
        u = pila.pop()
        for v in adj[u]:
            if not visto[v]:
                visto[v] = True
                pila.append(v)

Todos los DFS juntos visitan cada nodo una vez: O(n + m).

Una componente conexa es un grupo de nodos con camino entre cualquier par, que no se puede agrandar. Un nodo sin aristas, como el 10, es una componente de un solo nodo. Este código es la base de Building Roads en la sesión 2.

Grillas como grafos

Cada celda es un nodo y sus vecinas son las aristas.

Grafo implícito

Los vecinos salen de dx y dy

for dx, dy in ((1, 0), (-1, 0), (0, 1), (0, -1)):
    nx, ny = x + dx, y + dy
    if 0 <= nx < n and 0 <= ny < m:
        if g[nx][ny] == ".":
            ...   # (nx, ny) es una vecina libre

No hace falta construir una lista de adyacencia: los vecinos de cada celda se calculan cuando se necesitan, como en la semana 4.

Una grilla de n × m tiene n · m nodos y cada uno a lo sumo 4 aristas. Un recorrido cuesta O(n · m).

Hacer clic en una celda: en verde las vecinas a las que se puede pasar, en rojo las paredes y con borde punteado las posiciones fuera de la grilla. La grilla es el ejemplo de Counting Rooms.

Resumen

Reglas para grafos en Python

  1. Leer con lista de adyacencia: adj = [[] for _ in range(n + 1)].
  2. En un grafo no dirigido, agregar la arista en los dos sentidos.
  3. DFS con una lista como pila; marcar el nodo al meterlo.
  4. Componentes: un DFS desde cada nodo sin visitar.
  5. En una grilla, los vecinos salen de dx y dy, revisando los límites.
  6. Un recorrido completo cuesta O(n + m), y O(n · m) en una grilla.
