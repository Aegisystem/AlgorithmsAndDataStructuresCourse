Parte 1

BFS

Recorrer por capas: primero los nodos a distancia 1, luego los de distancia 2, y así.

BFS

Recorrido en anchura con una cola

from collections import deque

dist = [-1] * (n + 1)    # -1: no visitado
dist[s] = 0
cola = deque([s])
while cola:
    u = cola.popleft()
    for v in adj[u]:
        if dist[v] == -1:
            dist[v] = dist[u] + 1
            cola.append(v)

Es el DFS de la sesión 1 con una cola en lugar de una pila. También es O(n + m).

Avanzar paso a paso desde el nodo 1. El número debajo de cada nodo es su distancia. La cola siempre tiene nodos de una distancia d seguidos de nodos de distancia d + 1, nunca más. Por eso los nodos salen en orden de distancia.

Distancias mínimas

Por qué BFS da el camino con menos aristas

Un nodo a distancia d + 1 tiene un vecino a distancia d. BFS saca todos los nodos de distancia d antes que los de d + 1, así que el primero que descubre a un nodo es un vecino a la menor distancia posible.

DFS no sirve para esto. En el ciclo 1 – 2 – 3 – 4 – 5 – 1, un DFS recursivo que empieza por el 2 recorre 1, 2, 3, 4, 5 y llega al 5 con 4 aristas, aunque el 5 es vecino del 1.

BFS cuenta aristas. Si las aristas tienen pesos distintos, hace falta Dijkstra (semana 13).

Cuándo usar cada uno

  • Visitar todo lo alcanzable, contar componentes o regiones: DFS o BFS.
  • Menor cantidad de pasos o de movimientos: BFS.
  • Menor suma de pesos: Dijkstra.
Reconstruir el camino

Un arreglo de padres

# en el BFS, al descubrir v desde u:
padre[v] = u

# de t hacia atrás hasta s
camino = [t]
while camino[-1] != s:
    camino.append(padre[camino[-1]])
camino.reverse()

padre[v] es el nodo desde el que se descubrió v. Las aristas (padre[v], v) forman un árbol: el árbol de BFS.

En verde está el árbol de BFS desde el nodo 1; en azul, el camino al nodo elegido. El camino sale al revés (de t a s), por eso se invierte al final. El número debajo de cada nodo es su padre.

BFS multifuente

Distancia a la fuente más cercana

cola = deque()
for x, y in fuentes:
    dist[x][y] = 0
    cola.append((x, y))
# ... el mismo BFS de siempre

Todas las fuentes entran a la cola con distancia 0. El BFS avanza desde todas a la vez, y cada celda recibe la distancia a la fuente más cercana.

Cuesta lo mismo que un solo BFS: O(n · m) en una grilla. Hacer un BFS por cada fuente costaría O(k · n · m).

Avanzar paso a paso: cada paso es una capa. Las dos celdas S son las fuentes. Ejemplo de uso: la distancia de cada celda a la salida más cercana, o el momento en que un incendio que empieza en varios puntos llega a cada celda.

Bipartición

Pintar con dos colores

color = [0] * (n + 1)   # 0: sin color
color[s] = 1
cola = deque([s])
while cola:
    u = cola.popleft()
    for v in adj[u]:
        if color[v] == 0:
            color[v] = 3 - color[u]
            cola.append(v)
        elif color[v] == color[u]:
            ...   # no es bipartito

Un grafo es bipartito si sus nodos se pueden pintar con dos colores sin que una arista una dos del mismo color. 3 - color[u] cambia 1 por 2 y 2 por 1.

Avanzar paso a paso con cada grafo. Un grafo es bipartito si y solo si no tiene ciclos de longitud impar. Con la arista 1–3 aparece el triángulo 1, 2, 3 y dos vecinos quedan del mismo color (arista roja). Si el grafo no es conexo, se repite desde cada nodo sin color, como con las componentes.

Idea · CSES 1192

Counting Rooms

Pregunta para el grupo

Si la grilla es un grafo, ¿qué es un cuarto?

Una componente conexa de casillas de piso. La respuesta es la cantidad de componentes.
Se recorre la grilla; en cada casilla de piso sin visitar empieza un cuarto nuevo y un flood fill lo marca entero. Es O(n · m).

Solución · CSES 1192 · Counting Rooms

Un flood fill por cuarto

def main():
    n, m = map(int, input().split())
    g = [input() for _ in range(n)]
    visto = [[False] * m for _ in range(n)]
    cuartos = 0
    for i in range(n):
        for j in range(m):
            if g[i][j] == "#" or visto[i][j]:
                continue
            cuartos += 1
            visto[i][j] = True
            pila = [(i, j)]
            while pila:
                x, y = pila.pop()
                for dx, dy in ((1, 0), (-1, 0), (0, 1), (0, -1)):
                    nx, ny = x + dx, y + dy
                    if (0 <= nx < n and 0 <= ny < m
                            and g[nx][ny] == "." and not visto[nx][ny]):
                        visto[nx][ny] = True
                        pila.append((nx, ny))
    print(cuartos)

main()

Cada casilla entra una vez a la pila: O(n · m) = 10⁶ en el peor caso.

Con una grilla de 1000 × 1000 toda de piso (un solo cuarto) tardó 0.09 s (PyPy 3.11, Apple M4).

La pila guarda tuplas (x, y). Otra opción es guardar un solo entero x · m + y, como en la semana 4; en PyPy la diferencia con 10⁶ casillas es pequeña.

Solución · CSES 1667 · Message Route

BFS con padres

Leer y recorrer 
from collections import deque

def main():
    n, m = map(int, input().split())
    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        a, b = map(int, input().split())
        adj[a].append(b)
        adj[b].append(a)
    padre = [-1] * (n + 1)
    padre[1] = 0
    cola = deque([1])
    while cola:
        u = cola.popleft()
        for v in adj[u]:
            if padre[v] == -1:
                padre[v] = u
                cola.append(v)
Reconstruir la ruta 
    if padre[n] == -1:
        print("IMPOSSIBLE")
        return
    camino = [n]
    while camino[-1] != 1:
        camino.append(padre[camino[-1]])
    camino.reverse()
    print(len(camino))
    print(" ".join(map(str, camino)))

main()

O(n + m). Con un camino de 10⁵ computadores tardó 0.07 s (PyPy 3.11, Apple M4).

padre[1] = 0 marca el 1 como visitado y detiene la reconstrucción, porque ningún computador se llama 0.

Solución · CSES 1193 · Labyrinth

BFS en la grilla y letras como padres

Leer y recorrer 
from collections import deque

def main():
    n, m = map(int, input().split())
    g = [input() for _ in range(n)]
    for i in range(n):
        if "A" in g[i]:
            ax, ay = i, g[i].index("A")
        if "B" in g[i]:
            bx, by = i, g[i].index("B")
    paso = [[""] * m for _ in range(n)]
    paso[ax][ay] = "*"
    movs = ((1, 0, "D"), (-1, 0, "U"),
            (0, 1, "R"), (0, -1, "L"))
    cola = deque([(ax, ay)])
    while cola:
        x, y = cola.popleft()
        for dx, dy, c in movs:
            nx, ny = x + dx, y + dy
            if not (0 <= nx < n and 0 <= ny < m):
                continue
            if g[nx][ny] != "#" and paso[nx][ny] == "":
                paso[nx][ny] = c
                cola.append((nx, ny))
Reconstruir el camino 
    if paso[bx][by] == "":
        print("NO")
        return
    atras = {"D": (-1, 0), "U": (1, 0),
             "R": (0, -1), "L": (0, 1)}
    camino = []
    x, y = bx, by
    while paso[x][y] != "*":
        c = paso[x][y]
        camino.append(c)
        x += atras[c][0]
        y += atras[c][1]
    camino.reverse()
    print("YES")
    print(len(camino))
    print("".join(camino))

main()

O(n · m). Con 1000 × 1000 tardó 0.11 s (PyPy 3.11, Apple M4).

paso guarda "" para las casillas sin visitar y "*" para A. Esas dos marcas reemplazan al arreglo de visitados.

Resumen

Reglas para BFS

  1. BFS usa deque: append al final y popleft al inicio.
  2. Marcar la distancia (o el padre) al meter el nodo en la cola.
  3. Sin pesos, BFS da la menor cantidad de aristas desde el inicio.
  4. El camino sale siguiendo los padres desde el final, y se invierte.
  5. Varias fuentes: todas entran a la cola con distancia 0.
  6. Bipartito: pintar con 3 - color[u]; dos vecinos del mismo color lo impiden.
