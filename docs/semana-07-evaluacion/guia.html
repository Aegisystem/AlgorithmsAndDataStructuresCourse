Tipo 1 · Complejidad

¿Cuál es la complejidad de cada fragmento?

# a)
for i in range(n):
    for j in range(i, n):
        total += 1
O(n²): son n + (n − 1) + … + 1 = n(n + 1)/2 vueltas. 
# b)
i = 1
while i < n:
    i *= 2
O(log n): i se duplica en cada vuelta. 
# c) b es una lista de m elementos
for x in a:          # a tiene n elementos
    if x in b:
        c += 1
O(n · m), por el in sobre una lista. Con sb = set(b) queda O(n + m). 
# d) t es un string de largo n
s = ""
for ch in t:
    s += ch
O(n²) en PyPy, porque cada += copia el string. Con una lista y "".join es O(n).

Tipo 4 · Error

¿Qué está mal en cada código?

M = [[0] * m] * n
M[0][0] = 1
Las n filas son la misma lista, así que el 1 aparece en toda la columna 0. Se crea con [[0] * m for _ in range(n)]. 
lo, hi = 0, n
while lo <= hi:
    mid = (lo + hi) // 2
    if a[mid] >= x:
        hi = mid
    else:
        lo = mid + 1
Con lo == hi el bucle no termina, y con mid = n da IndexError. La condición es lo < hi. 
q = list(range(n))
while q:
    x = q.pop(0)
    ...
pop(0) es O(n), así que el bucle es O(n²). Con deque y popleft() es O(n).
Tipo 5 · Escribir

Escribir una solución a mano

Lea n palabras, una por línea, e imprima la que más se repite. Si hay empate, la que apareció primero.

from collections import Counter

def main():
    n = int(input())
    w = [input() for _ in range(n)]
    print(Counter(w).most_common(1)[0][0])

main()

most_common deja los empates en el orden en que aparecieron. Es O(n).

Sin usar bisect, escriba una función que reciba una lista ordenada y un x, y devuelva cuántos valores son ≤ x.

def cuantos(a, x):
    lo, hi = 0, len(a)
    while lo < hi:
        mid = (lo + hi) // 2
        if a[mid] > x:
            hi = mid
        else:
            lo = mid + 1
    return lo

Es la primera posición con a[i] > x, igual que bisect_right. Es O(log n).
