Tipo 1 · Complejidad

¿Cuál es la complejidad de cada fragmento?

# a)
for mask in range(1 << n):
    for i in range(n):
        if mask >> i & 1:
            s += a[i]
O(2ⁿ · n): 2ⁿ subconjuntos y n bits en cada uno. 
# b)
i = n
while i > 0:
    s += bit[i]
    i -= i & -i
O(log n): cada vuelta apaga un bit de i.

¿Qué técnica usaría?

Menor cantidad de conexiones para ir del computador 1 al n.BFS Ruta más corta entre ciudades con carreteras de longitudes distintas.Dijkstra Ordenar cursos que tienen requisitos, o decir que es imposible.orden topológico (Kahn) Reparar carreteras para conectar todo con el menor costo.Kruskal con Union-Find 2·10⁵ consultas que cambian un valor o piden la suma de un rango.Fenwick Mínimo de 2·10⁵ rangos de un arreglo que no cambia.sparse table Contar subarreglos con suma k, con valores negativos.prefijas + dict n ≤ 20: repartir en dos grupos con la menor diferencia.bitmask (2ⁿ)

Tipo 4 · Error

¿Qué está mal?

# mochila 0/1
for w, v in objetos:
    for c in range(w, W + 1):
        dp[c] = max(dp[c],
                    dp[c - w] + v)
Al recorrer c de menor a mayor, dp[c − w] ya puede incluir el mismo objeto, y se usa varias veces. Para la 0/1, c va de W a w. 
# suma de x_a .. x_b
p = list(accumulate(x, initial=0))
print(p[b] - p[a])
Deja fuera x_a. Es p[b] - p[a - 1].

Tipo 5 · Escribir

Escribir una solución a mano

Escriba una función que reciba una lista no vacía y devuelva la mayor suma de un subarreglo.

def mayor_suma(a):
    mejor = actual = a[0]
    for v in a[1:]:
        actual = max(v, actual + v)
        mejor = max(mejor, actual)
    return mejor

Kadane, O(n). Empezar en a[0] y no en 0 cubre el caso con todos negativos.

Sin recursión, cuente las componentes conexas de un grafo con nodos 1..n y lista de adyacencia adj.

def componentes(n, adj):
    visto = [False] * (n + 1)
    c = 0
    for s in range(1, n + 1):
        if not visto[s]:
            c += 1
            visto[s] = True
            pila = [s]
            while pila:
                u = pila.pop()
                for v in adj[u]:
                    if not visto[v]:
                        visto[v] = True
                        pila.append(v)
    return c

Preparación

Cómo prepararse

  1. Volver a resolver, sin mirar la solución, los problemas de las prácticas de las semanas 12 a 15.
  2. Escribir de memoria BFS, Dijkstra, Union-Find y el Fenwick, y probarlos con el ejemplo de un problema.
  3. Hacer en papel la traza de un BFS, de una tabla de DP y de prefijo en un Fenwick.
  4. Para cada problema de los talleres, escribir en una línea la técnica y la complejidad.
  5. Repasar los resúmenes de las clases de las semanas 8 a 15.

Si la carga de la semana es excesiva, el parcial puede ir en la S1 de la semana 15, siempre que quede dentro del corte 3 (ver PROGRAMA.md, sección 5).
