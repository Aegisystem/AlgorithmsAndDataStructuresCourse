Problema: dado un arreglo de n ≤ 2·10⁵ enteros, contar cuántos valores distintos tiene.

# Solución A
vistos = []
for x in a:
    if x not in vistos:   # recorre la lista

# Solución B

Solución A TLE

Cada x not in vistos recorre hasta n elementos. En total son hasta n² = 4·10¹⁰ comparaciones.

Solución B AC

Insertar en un set cuesta O(1) en promedio. En total son unas 2·10⁵ operaciones.

Las dos dan la respuesta correcta. Lo que cambia es la cantidad de operaciones.

Idea · CSES 1070

  
Permutations

  

    
Pregunta para el grupo
¿Para qué valores pequeños de n no existe respuesta? Pruebe a mano con n = 2, 3 y 4.

    
n = 2 y n = 3 no tienen solución. Desde n = 4 sirve poner primero los pares y después los impares: dos pares seguidos difieren en 2, igual que dos impares.

Solución · CSES 1070 · Permutations

  
Una permutación sin vecinos consecutivos

  

    

      
Construir una permutación de 1…n donde dos vecinos nunca difieran en 1. Si no existe, imprimir NO SOLUTION. Restricción: n ≤ 10⁶.

      

        

      

    

    

      
def main():
    n = int(input())
    if n == 2 or n == 3:
        print("NO SOLUTION")
        return
    pares = list(range(2, n + 1, 2))
    impares = list(range(1, n + 1, 2))
    print(*(pares + impares))

main()

      
Dos pares seguidos difieren en 2. Lo mismo dos impares. En la unión, el último par (n o n − 1) y el 1 difieren en más de 1 cuando n ≥ 4.

    

  

  

    
Primero "Probar todas" con n = 3 y n = 4 para ver que n = 3 no tiene solución y n = 4 tiene dos (2 4 1 3 y 3 1 4 2). Luego mostrar la construcción.

    
Casos borde: n = 1 imprime "1". La búsqueda completa haría n! permutaciones: con n = 10⁶ es imposible, así que hace falta una construcción.
