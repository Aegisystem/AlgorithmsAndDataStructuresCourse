Parte 1

Crear y leer matrices

Una matriz en Python es una lista de listas.

Crear una matriz

Por qué [[0]*m]*n falla

M = [[0] * m] * n      # n referencias a la MISMA fila

Haga clic en una celda. Las n filas son la misma lista, así que el cambio aparece en todas.

M = [[0] * m for _ in range(n)]   # n filas distintas

Cada vuelta del for crea una lista nueva. El cambio aparece en una sola celda.

[0] * m sí está bien porque los enteros no se modifican: M[i][j] = 1 reemplaza el valor en la fila. El problema es multiplicar la lista de filas. Se puede comprobar con M[0] is M[1]. Python Tutor (pythontutor.com) dibuja esto con flechas.

Leer matrices

Matrices de números y grillas de caracteres

# n filas de m números
n, m = map(int, input().split())
M = [list(map(int, input().split())) for _ in range(n)]

# n filas de caracteres '#' y '.'
g = [input() for _ in range(n)]
g[i][j]          # carácter de la fila i, columna j

# si hay que modificar la grilla
g = [list(input()) for _ in range(n)]

Una fila leída como string no se puede modificar. Para cambiar celdas se lee como lista.

Diagonales

  
Cada diagonal tiene un valor constante

  

    

      

      
Haga clic en una celda.

    

    

      

      
    
        
  • En la diagonal que baja a la derecha, i − j es constante. La principal es i − j = 0.
    • 
        
  • En la diagonal que baja a la izquierda, i + j es constante. La secundaria es i + j = n − 1.
    • 
        
  • Hay n + m − 1 diagonales de cada tipo.
    • 
        
  • Para agruparlas: diag[i - j + m - 1] y anti[i + j].
    • 
      

      
En el problema de las N reinas (semana 11) se usan estos índices para saber si dos reinas se atacan.

Multiplicación y aplanado

  
Producto de matrices en O(n³) y matrices guardadas en una sola lista.






  
Multiplicación

  
Fila de A por columna de B

  

    

      
×
      
=
      

    

    

    

      
# A es n×m, B es m×p, C es n×p
C = [[0] * p for _ in range(n)]
for i in range(n):
    for j in range(p):
        s = 0
        for k in range(m):
            s += A[i][k] * B[k][j]
        C[i][j] = s

      

        
Tres bucles anidados: O(n · m · p). Con matrices n × n es O(n³).

        
Con n = 500 son 1.25·10⁸ multiplicaciones. Con PyPy tardó 0.19 s en un Apple M4; en el juez queda más cerca del límite.

        
Extensión: elevando una matriz 2 × 2 a la potencia k se calcula el k-ésimo Fibonacci en O(log k). Se retoma como reto en la semana 8.

      

    

  






  
Aplanar

  
Una matriz en una sola lista

  

    

      

      

      

    

    

      
k = i * m + j          # (i, j) → k
i, j = divmod(k, m)    # k → (i, j)
vis = bytearray(n * m) # visitados, 1 byte por celda

      
Cada celda queda representada por un solo entero. En BFS (semana 12) la cola guarda enteros en lugar de tuplas (i, j).

      
En PyPy también es más rápido: sumar los 4 vecinos de 10⁶ celdas tardó 0.005 s con M[i][j] y 0.002 s aplanado.

    

  

  
Medido con PyPy 3.11, Apple M4. Guardar la fila en una variable (row = M[i]) también bajó a 0.002 s. Sirve para representar estados con un entero y para usar bytearray. En PyPy la lista plana suele ser más rápida.

Solución · CSES 1071 · Number Spiral

  
El valor en la fila y, columna x

  

    

      

      
Haga clic en una celda. Las capas se colorean por paridad.

    

    

      

      
def valor(y, x):
    z = max(y, x)              # capa
    if z % 2 == 0:
        if y == z:
            return z * z - x + 1
        return (z - 1) ** 2 + y
    else:
        if x == z:
            return z * z - y + 1
        return (z - 1) ** 2 + x

      
y, x ≤ 10⁹ y hasta 10⁵ consultas: no se puede construir la grilla. Cada consulta es O(1). El resultado llega a 10¹⁸ y Python no se desborda.

    

  

  
La capa z termina en z². En las capas pares el recorrido baja por la columna z y luego va a la izquierda por la fila z; en las impares es al revés. Mostrar la fila 2, columna 3 (valor 8) y la fila 4, columna 2 (valor 15), que son ejemplos del enunciado.

Entrada y salida rápida

  
Por qué es más rápida

  

    

      
    
        
  • input() hace trabajo extra en cada llamada: entre otras cosas, vacía la salida pendiente antes de leer. sys.stdin.readline lee la línea directamente.
    • 
        
  • print hace una escritura por cada línea. join arma un solo string y sys.stdout.write lo escribe una vez.
    • 
        
  • La diferencia se nota desde unas 10⁵ líneas. Con pocas líneas da lo mismo.
    • 
      

      
# leer toda la entrada de una vez
data = sys.stdin.buffer.read().split()
t = int(data[0])
# data[1], data[2], ... son bytes; int() los convierte

    

    

      
Leer 10⁶ enteros, uno por línea

      
input()
0.13 s

      
readline
0.07 s

      
Escribir 10⁶ enteros, uno por línea

      
print
0.025 s

      
join + write
0.014 s

      
PyPy 3.11, Apple M4, salida a /dev/null.

    

  

  
Leer todo con sys.stdin.buffer.read().split() es la forma más rápida. Sirve cuando no importa dónde termina cada línea; con grillas de caracteres conviene seguir leyendo por líneas.

Solución · AtCoder · grillas

  
Dos problemas B de grillas

  

    

      
ABC075 B · Minesweeper

      
Cambiar cada . por la cantidad de # entre sus 8 vecinos.

      
for i in range(h):
    fila = []
    for j in range(w):
        if g[i][j] == "#":
            fila.append("#")
            continue
        c = 0
        for di in (-1, 0, 1):
            for dj in (-1, 0, 1):
                ni, nj = i + di, j + dj
                if 0 <= ni < h and 0 <= nj < w and g[ni][nj] == "#":
                    c += 1
        fila.append(str(c))
    print("".join(fila))

    

    

      
ABC107 B · Grid Compression

      
Quitar las filas y columnas que solo tienen ..

      
g = [f for f in g if "#" in f]        # filas
cols = [c for c in zip(*g) if "#" in c] # columnas
g = ["".join(f) for f in zip(*cols)]    # volver a filas

      
Las columnas se filtran transponiendo con zip(*g), filtrando y transponiendo otra vez.
