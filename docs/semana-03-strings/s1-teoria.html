Parte 1

Índices y slicing

Cada carácter tiene un índice positivo y uno negativo.

Slicing

s[inicio:fin:paso]

  • s[i] es el carácter en la posición i. s[-1] es el último.
  • s[a:b] va desde a hasta b − 1. El fin no se incluye.
  • Si falta el inicio o el fin, se toma desde el borde.
  • s[::-1] recorre al revés: invierte el string.
  • Un slice crea un string nuevo: cuesta O(b − a).
  • s[20] da IndexError, pero s[2:20] no da error.

Probar con el grupo: s[2:5], s[-3:], s[::2], s[::-1], s[5:2:-1]. Preguntar el resultado antes de mover los controles.

Palíndromos

Un palíndromo se lee igual al revés

# forma corta: crea una copia invertida, O(n)
es_pal = s == s[::-1]

# dos punteros: no crea copias
i, j = 0, len(s) - 1
es_pal = True
while i < j:
    if s[i] != s[j]:
        es_pal = False
        break
    i += 1
    j -= 1

Las dos son O(n). La de dos punteros sirve cuando hay que saber dónde falla, por ejemplo para quitar un carácter.

Parte 2

Los strings son inmutables

Un string no se puede modificar. Cada cambio crea uno nuevo.

Inmutabilidad

Construir un string con una lista

s = "hola"
s[0] = "H"    # TypeError: 'str' object does not
              # support item assignment

# cambiar un carácter: pasar por una lista
t = list(s)
t[0] = "H"
s = "".join(t)          # "Hola"
# construir una respuesta larga
partes = []
for c in s:
    partes.append(c.upper())
res = "".join(partes)   # O(n) en total

s = s + c copia los caracteres de s en un string nuevo. En un bucle de n vueltas, se copian 1 + 2 + … + n ≈ n²/2 caracteres.

Medición

2·10⁵ concatenaciones

s = c + s (al inicio)
0.44 s
s += c
0.44 s
lista + "".join
0.002 s

En PyPy, s += c copia el string completo en cada vuelta: es O(n²). Con 10⁶ concatenaciones tardó 11.7 s; con join, 0.015 s.

PyPy 3.11, Apple M4.

Con el intérprete normal de Python a veces s += c es rápido por una optimización interna, y por eso hay estudiantes que no ven el problema al probar en su computador. En PyPy no existe esa optimización. Regla del curso: lista y join.

Parte 4

Caracteres y frecuencias

Cada carácter es un número. Eso permite usarlo como índice.

ord y chr

Cada carácter tiene un código

ord("a")              # 97
chr(98)               # "b"
ord(c) - ord("a")     # posición de c: 0..25
chr(ord("a") + i)     # letra número i
ord("A")              # 65: mayúsculas antes

Cifrado César: chr((ord(c) - 97 + k) % 26 + 97). El % 26 hace que después de la z siga la a.

Frecuencias

Contar letras con un arreglo de 26

cnt = [0] * 26
for c in s:
    cnt[ord(c) - 97] += 1

# con la biblioteca
from collections import Counter
cnt = Counter(s)
# con s = "banana": a: 3, n: 2, b: 1

El arreglo de 26 sirve cuando las letras son minúsculas. Counter sirve para cualquier carácter o palabra.

Anagramas

Dos palabras son anagramas si tienen las mismas frecuencias

# O(n log n)
sorted(a) == sorted(b)

# O(n)
Counter(a) == Counter(b)

Cada letra tiene dos barras: la de a a la izquierda (azul) y la de b a la derecha (verde). Las letras en rojo tienen frecuencias distintas.

Parte 5

Números y strings

Dígitos, sumas de dígitos y cambios de base.

Bases

De decimal a binario, dividiendo entre 2

bin(13)          # '0b1101'
bin(13)[2:]      # '1101'
int("1101", 2)   # 13
int("ff", 16)    # 255

# suma de dígitos
sum(map(int, str(n)))

# a una base b cualquiera
def a_base(n, b):
    if n == 0:
        return "0"
    d = []
    while n > 0:
        d.append(str(n % b))
        n //= b
    return "".join(reversed(d))

Los residuos se leen de abajo hacia arriba. a_base funciona para bases hasta 10; para base 16 hay que usar letras para los dígitos de 10 a 15.

Parte 6

Comparación lexicográfica

El orden del diccionario, carácter por carácter.

Orden lexicográfico

Gana el primer carácter distinto

¿Cuál es menor? Haga clic para ver la respuesta.

Si un string es prefijo del otro, el más corto es menor. Las mayúsculas (65–90) van antes que las minúsculas (97–122).

"10" < "9" es True porque compara el carácter "1" con "9". Para comparar números leídos como texto hay que convertirlos con int. Esto conecta con CF 112A, donde hay que pasar todo a minúsculas antes de comparar.

Solución · Codeforces 71A y 118A

Abreviar palabras y procesar letras

71A · Way Too Long Words

Si una palabra tiene más de 10 letras, se escribe primera letra + cantidad de letras del medio + última letra.

def main():
    for _ in range(int(input())):
        w = input()
        if len(w) > 10:
            w = w[0] + str(len(w) - 2) + w[-1]
        print(w)

main()

"localization" → "l10n"

118A · String Task

Quitar las vocales (incluida la y), poner un punto antes de cada consonante y pasar a minúsculas.

def main():
    s = input().lower()
    res = []
    for c in s:
        if c not in "aoyeui":
            res.append("." + c)
    print("".join(res))

main()

Comparar sin mayúsculas y contar distintos

112A · Petya and Strings

Comparar dos strings sin distinguir mayúsculas. Imprimir −1, 0 o 1.

def main():
    a = input().lower()
    b = input().lower()
    if a < b:
        print(-1)
    elif a > b:
        print(1)
    else:
        print(0)

Problema · CSES 1755

Palindrome Reorder

Se da un string. Hay que reordenar sus letras para formar un palíndromo.

Entrada
Un string de n letras de la A a la Z.
Salida
Un palíndromo con esas letras, o NO SOLUTION si no se puede. Si hay varios, cualquiera sirve.
Restricciones
1 ≤ n ≤ 10⁶
Entrada
AAAACACBA
Salida
AACABACAA

Enunciado original: https://cses.fi/problemset/task/1755

Leer el enunciado con el grupo y resolver el ejemplo a mano antes de pasar a la solución.

Solución · CSES 1755 · Palindrome Reorder

Reordenar las letras para formar un palíndromo

def main():
    s = input()
    cnt = [0] * 26
    for c in s:
        cnt[ord(c) - 65] += 1
    impares = []
    for i in range(26):
        if cnt[i] % 2 == 1:
            impares.append(i)
    if len(impares) > 1:
        print("NO SOLUTION")
    else:
        mitad = []
        for i in range(26):
            letra = chr(65 + i)
            mitad.append(letra * (cnt[i] // 2))
        mitad = "".join(mitad)
        centro = ""
        if impares:
            centro = chr(65 + impares[0])
        print(mitad + centro + mitad[::-1])

main()

Un palíndromo tiene a lo sumo una letra con frecuencia impar (la del centro). Con n ≤ 10⁶ la solución es O(n + 26). Cualquier palíndromo válido es aceptado.
