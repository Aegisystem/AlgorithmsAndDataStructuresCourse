Parte 1

Divisibilidad

División entera, residuo, máximo común divisor y mínimo común múltiplo.

// y %

División entera y residuo con negativos

a = b = a // b= a % b=

En Python, a // b redondea hacia abajo: -7 // 2 es −4. Siempre se cumple a == b * (a // b) + a % b.

Por eso a % b tiene el signo de b: -7 % 3 es 2. Con b > 0, el residuo queda entre 0 y b − 1.

En C++ y Java, −7 / 2 es −3 y −7 % 3 es −1. Al leer soluciones en esos lenguajes hay que tenerlo en cuenta.

divmod(a, b) devuelve los dos valores a la vez.

Probar a = −7, b = 2 y a = 7, b = −3. Que el residuo nunca sea negativo (con b > 0) evita errores en aritmética modular: (a - b) % m ya queda entre 0 y m − 1.

Techo, gcd y lcm

Redondear hacia arriba y divisores comunes

# techo de a / b, con enteros (a, b > 0)

-(-a // b)

import math
math.gcd(48, 18)    # 6
math.lcm(4, 6)      # 12
math.gcd(*a)        # de toda una lista

math.ceil(a / b) pasa por un float. Con valores cerca de 10¹⁸ el float pierde precisión y la respuesta puede salir mal.

gcd usa el algoritmo de Euclides: gcd(a, b) = gcd(b, a % b), hasta que b es 0.

Hace O(log min(a, b)) pasos. Además, lcm(a, b) = a // gcd(a, b) * b.

Parte 2

Primos y divisores

Probar hasta √n y marcar múltiplos con la criba.

Divisores

Basta probar hasta √n

def es_primo(n):
    if n < 2:
        return False
    d = 2
    while d * d <= n:
        if n % d == 0:
            return False
        d += 1
    return True

def divisores(n):
    r = []
    d = 1
    while d * d <= n:
        if n % d == 0:
            r.append(d)
            if d != n // d:
                r.append(n // d)
        d += 1
    return r

Si d divide a n, también n / d lo divide, y uno de los dos es ≤ √n. Por eso se prueba solo hasta √n: con n = 10⁹ son unas 31 623 vueltas. Se usa d * d <= n en lugar de d <= n ** 0.5 para no depender de floats. Probar con un cuadrado (36) para ver por qué hace falta el if d != n // d.

Criba de Eratóstenes

Todos los primos hasta N

es = bytearray([1]) * (N + 1)
es[0] = es[1] = 0
i = 2
while i * i <= N:
    if es[i]:
        for j in range(i * i, N + 1, i):
            es[j] = 0
    i += 1
# es[x] == 1 si x es primo

Cuesta O(N log log N). Con N = 10⁷ tardó 0.017 s con bytearray y 0.087 s con una lista de True/False (PyPy 3.11, Apple M4).

Se empieza en i · i porque los múltiplos menores de i ya fueron tachados por un primo menor. Un bytearray usa 1 byte por posición: con N = 10⁷ son unos 10 MB. Hasta 10⁷ hay 664 579 primos.

Gauss sumó 1 + 2 + … + 100 juntando parejas: 1 + 100, 2 + 99, … Son 50 parejas de 101, o sea 5050.

La cantidad de parejas también se escribe C(n, 2): se escoge el primero de n formas y el segundo de n − 1, y cada pareja quedó contada dos veces.

En Missing Number (semana 1) se usó la primera fórmula: el que falta es n * (n + 1) // 2 - sum(a).

Las fórmulas usan // porque el producto siempre es par, y así el resultado queda entero. Con / sale un float, que pierde precisión cerca de 10¹⁶.

Solución · CSES 1618 y 1754

Contar factores y revisar condiciones

Trailing Zeros

Ceros al final de n!.

def main():
    n = int(input())
    ceros = 0
    p = 5
    while p <= n:
        ceros += n // p
        p *= 5
    print(ceros)

main()

Coin Piles

¿Se vacían las dos pilas quitando 2 y 1?

def main():
    t = int(input())
    res = []
    for _ in range(t):
        a, b = map(int, input().split())
        if (a + b) % 3 == 0 and \
           2 * min(a, b) >= max(a, b):
            res.append("YES")
        else:
            res.append("NO")
    print("\n".join(res))

main()

Parte 4

Aritmética modular

Trabajar con el residuo para que los números no crezcan.

Módulo 10⁹ + 7

Sacar el módulo en cada paso

MOD = 10**9 + 7

(a + b) % MOD
(a - b) % MOD       # queda entre 0 y MOD - 1
(a * b) % MOD

r = 1
for x in a:
    r = r * x % MOD   # no esperar al final

pow(a, b, MOD)      # a^b mod MOD en O(log b)

Si la respuesta puede ser enorme, el enunciado pide imprimirla módulo 10⁹ + 7, que es primo.

La suma, la resta y el producto se pueden reducir en cada paso y el resultado final es el mismo.

La división no funciona así: (a // b) % m no se obtiene de a % m y b % m. Para dividir hace falta el inverso modular, pow(b, -1, MOD), que queda como extensión.

En Python los enteros no se desbordan. Cada operación con un entero cuesta según su cantidad de dígitos, así que un número enorme es lento.

Medición

Calcular (10⁹)ᵇ mod 10⁹ + 7

a ** b % MOD, b = 10⁵
0.04 s
a ** b % MOD, b = 10⁶
1.51 s
a ** b % MOD, b = 10⁷
57.6 s
pow(a, b, MOD), b = 10⁷
0.000004 s

a ** b calcula el número completo: con b = 10⁶ tiene unos 3·10⁷ bits. pow con tres argumentos reduce en cada paso y nunca pasa de MOD².

PyPy 3.11, Apple M4.

Exponenciación rápida

Cómo calcula pow en O(log b)

a = 3, m = 1000, b =
def potencia(a, b, m):
    r = 1
    a %= m
    while b > 0:
        if b & 1:          # bit más bajo de b
            r = r * a % m
        a = a * a % m      # a, a², a⁴, a⁸, ...
        b >>= 1            # quitar ese bit
    return r

3¹³ = 3⁸ · 3⁴ · 3¹, porque 13 = 1101 en binario. El bucle recorre los bits de b: con b ≤ 10⁹ son 30 vueltas.

Los operadores & y >> se ven en la parte 5. Aquí basta saber que b & 1 es el último bit de b y que b >>= 1 lo quita. En los problemas se usa pow(a, b, m), que hace lo mismo.

Parte 5

Bits

Un entero es una fila de bits, y se puede operar bit por bit.

Operadores de bits

& | ^ ~ << >>

  • a & b: 1 donde los dos tienen 1.
  • a | b: 1 donde alguno tiene 1.
  • a ^ b: 1 donde son distintos.
  • ~a: invierte todos los bits; vale -a - 1.
  • a << k: corre k posiciones a la izquierda; vale a · 2ᵏ.
  • a >> k: corre k a la derecha; vale a // 2ᵏ.

bin(13) es '0b1101' e int("1101", 2) es 13.

Haga clic en los bits de a y b para cambiarlos. Los bits se numeran desde 0, de derecha a izquierda; el bit i vale 2ⁱ. ~a sale negativo porque en Python los enteros no tienen un número fijo de bits.

Un bit

Consultar, encender y apagar el bit i

x >> i & 1       # 1 si el bit i está encendido
x | (1 << i)     # encender el bit i
x & ~(1 << i)    # apagar el bit i
x ^ (1 << i)     # cambiar el bit i

x.bit_count()    # cantidad de bits en 1
x.bit_length()   # cuántos bits tiene en binario

# x es potencia de 2
x > 0 and x & (x - 1) == 0

Un entero de n bits puede representar un subconjunto de n elementos: el bit i indica si el elemento i está. En la semana 11 se recorren todos los subconjuntos con range(1 << n).

x & (x - 1) apaga el bit 1 más bajo de x. Si queda 0, x tenía un solo bit encendido.

Con 10⁶ números, x.bit_count() tardó 0.018 s y bin(x).count("1") 0.13 s (PyPy 3.11, Apple M4).

En Python, >> tiene más prioridad que &, así que x >> i & 1 es (x >> i) & 1. Ante la duda, poner paréntesis. Ejemplo para la potencia de 2: 8 = 1000 y 7 = 0111, así que 8 & 7 = 0.

XOR

Propiedades del XOR

  • a ^ a == 0 y a ^ 0 == a.
  • El orden no importa: a ^ b ^ a == b.
  • Si se hace XOR de una lista, los valores que aparecen un número par de veces se cancelan.

Missing Number (semana 1) sale también con XOR: se hace XOR de 1 a n y de los n − 1 números leídos. Todos se cancelan menos el que falta.

def main():
    n = int(input())
    a = list(map(int, input().split()))
    x = 0
    for i in range(1, n + 1):
        x ^= i
    for v in a:
        x ^= v
    print(x)      # el número que falta

main()

Ejemplo con n = 5 y la lista 2 3 1 5: (1^2^3^4^5) ^ (2^3^1^5) = 4. La misma idea encuentra el único número sin pareja en una lista donde todos los demás aparecen dos veces.

Idea · CSES 1072

Two Knights

Pregunta para el grupo

¿Cuántas parejas de casillas hay en total? ¿Cuántas de ellas se atacan?

En total hay k² · (k² − 1) / 2 parejas, la fórmula de parejas con n = k².
Dos caballos que se atacan ocupan esquinas opuestas de un rectángulo de 2 × 3 o de 3 × 2. Cada rectángulo tiene 2 de esas parejas.
Hay (k − 1)(k − 2) rectángulos de cada forma. La respuesta es k²(k² − 1)/2 − 4(k − 1)(k − 2).

Dejar uno o dos minutos para que el grupo responda. Después avanzar con → para mostrar la idea paso a paso.

Solución · CSES 1072 · Two Knights

Todas las parejas menos las que se atacan

def main():
    n = int(input())
    res = []
    for k in range(1, n + 1):
        total = k * k * (k * k - 1) // 2
        ataques = 4 * (k - 1) * (k - 2)
        res.append(total - ataques)
    print("\n".join(map(str, res)))

main()

k = 6: 36 · 35 / 2 − 4 · 5 · 4 = 630 − 80 = 550

Es O(n). La fórmula se comparó con una búsqueda completa para k ≤ 12.

Haga clic en una casilla para poner el caballo; las casillas en rojo son las que ataca. Sumar los ataques de todas las casillas da 160 = 2 · 80, porque cada pareja se cuenta desde sus dos casillas. Otra forma de llegar a la fórmula es sumar esos ataques casilla por casilla y dividir entre 2.
