Parte 1

Sumas prefijas

Se calculan una vez y cada consulta de suma sobre un rango cuesta O(1).

Medición

Sumar el rango en cada consulta

sum(x[a-1:b]), q = 2·10³
0.10 s
sum(x[a-1:b]), q = 2·10⁴
0.90 s
sumas prefijas, q = 2·10⁵
0.004 s

Cada consulta con sum recorre el rango: O(n) por consulta y O(n · q) en total. Con n = q = 2·10⁵ son del orden de 10¹⁰ operaciones.

n = 2·10⁵ y rangos aleatorios. Solo el cálculo, sin leer la entrada. PyPy 3.11, Apple M4.

Con q = 2·10⁴ ya se gasta casi el segundo entero; con las 2·10⁵ consultas del problema serían unos 9 s. Las sumas prefijas hacen O(n) trabajo una sola vez y después O(1) por consulta.

Sumas prefijas

p[i] es la suma de los primeros i valores

x
p
p = [0] * (n + 1)
for i in range(n):
    p[i + 1] = p[i] + x[i]

# lo mismo, con itertools
from itertools import accumulate
p = list(accumulate(x, initial=0))

# suma de x_a + ... + x_b (desde 1)
p[b] - p[a - 1]

p tiene n + 1 posiciones y p[0] = 0. La suma de a a b es lo que se acumula hasta b menos lo que se acumula hasta a − 1.

Cambiar a y b para ver qué dos casillas de p se restan. El p[0] = 0 evita un caso especial cuando a = 1. El arreglo es el del ejemplo de Static Range Sum Queries.

Idea · CSES 1646

Static Range Sum Queries

Pregunta para el grupo

Si ya se sabe la suma de los primeros 4 valores y la de los primeros 1, ¿cuánto suman los valores 2, 3 y 4?

La diferencia: 14 − 3 = 11. En general, x_a + … + x_b = p[b] − p[a − 1].
Se calcula p una vez en O(n) y cada consulta cuesta O(1). El total es O(n + q).

Dejar uno o dos minutos para que el grupo responda. Después avanzar con → para mostrar la idea paso a paso. Las sumas llegan a 2·10¹⁴; en Python no hay desbordamiento.

Solución · CSES 1646 · Static Range Sum Queries

Una resta por consulta

from itertools import accumulate

def main():
    n, q = map(int, input().split())
    x = list(map(int, input().split()))
    p = list(accumulate(x, initial=0))
    res = []
    for _ in range(q):
        a, b = map(int, input().split())
        res.append(p[b] - p[a - 1])
    print("\n".join(map(str, res)))

main()

O(n) para construir p y O(1) por consulta.

Las respuestas se guardan en una lista y se imprimen al final con un solo print.

Con la entrada máxima tardó 0.13 s (PyPy 3.11, Apple M4).

Parte 2

Sumas prefijas en 2D

La misma idea sobre una matriz, con inclusión y exclusión.

Prefijas 2D

P[i][j] cuenta el rectángulo de (1, 1) a (i, j)

Consulta (y1, x1, y2, x2):
# construir: fila por fila
P[i][j] = (P[i-1][j] + P[i][j-1]
           - P[i-1][j-1] + celda[i][j])

# consultar el rectángulo
(P[y2][x2] - P[y1-1][x2]
 - P[y2][x1-1] + P[y1-1][x1-1])

Al restar las filas de arriba y las columnas de la izquierda, la esquina se resta dos veces. Por eso se suma una vez al final.

A la izquierda está el bosque del ejemplo de Forest Queries (♣ es un árbol) y a la derecha la tabla P, con la fila 0 y la columna 0 en cero. Avanzar paso a paso: cada término de la fórmula se marca en el bosque y en la tabla. La construcción usa la misma idea: P[i][j] es lo de arriba más lo de la izquierda, menos la esquina que quedó dos veces, más la celda.

Idea · CSES 1652

Forest Queries

Pregunta para el grupo

Con P[i][j] = árboles de (1, 1) a (i, j), ¿qué rectángulos hay que quitarle a P[y2][x2] para que quede solo el de la consulta?

Las filas de arriba, P[y1 − 1][x2], y las columnas de la izquierda, P[y2][x1 − 1].
La esquina P[y1 − 1][x1 − 1] quedó restada dos veces, así que se suma una vez.
Construir P cuesta O(n²) = 10⁶ y cada consulta O(1).

Dejar uno o dos minutos para que el grupo responda. Después avanzar con → para mostrar la idea paso a paso.

Solución · CSES 1652 · Forest Queries

Inclusión y exclusión

def main():
    n, q = map(int, input().split())
    P = [[0] * (n + 1) for _ in range(n + 1)]
    for i in range(1, n + 1):
        fila = input()
        for j in range(1, n + 1):
            arbol = 1 if fila[j - 1] == "*" else 0
            P[i][j] = (P[i - 1][j] + P[i][j - 1]
                       - P[i - 1][j - 1] + arbol)
    res = []
    for _ in range(q):
        y1, x1, y2, x2 = map(int, input().split())
        res.append(P[y2][x2] - P[y1 - 1][x2]
                   - P[y2][x1 - 1] + P[y1 - 1][x1 - 1])
    print("\n".join(map(str, res)))

main()

La fila 0 y la columna 0 de P quedan en cero, igual que p[0] en 1D.

La grilla usa índices desde 0 (fila[j - 1]) y P desde 1.

Con n = 1000 y 2·10⁵ consultas tardó 0.11 s (PyPy 3.11, Apple M4).

Parte 3

Arreglo de diferencias

Sumar un valor a un rango completo en O(1).

Diferencias

Marcar dónde empieza y dónde termina el cambio

d
a
d = [0] * (n + 2)
for a, b, u in cambios:  # u de a a b
    d[a] += u
    d[b + 1] -= u

valor = [0] * (n + 1)
for i in range(1, n + 1):
    valor[i] = valor[i - 1] + d[i]

Cada cambio cuesta O(1). Al final, las sumas prefijas de d dan cuánto se le sumó a cada posición, en O(n).

Sirve cuando primero llegan todos los cambios y después se consultan los valores.

Avanzar paso a paso. Primero se aplican los tres cambios sobre d: +u en a y −u en b + 1. Después se recorre d sumando. El +u de d[a] llega a todas las posiciones desde a, y el −u de d[b + 1] lo cancela desde b + 1. Si los cambios y las consultas se mezclan, hace falta el árbol de Fenwick de la semana 15.

Parte 4

Prefijas y un dict

Contar subarreglos que suman k.

Prefijas con un dict

Subarreglos con suma x

a = [2, −1, 3, 5, −2] y x = 7.

a

La suma de a[i + 1..j] es p[j] − p[i]. Esa suma vale x cuando p[i] = p[j] − x.

Al llegar a la posición j se cuenta cuántas sumas prefijas anteriores valen p[j] − x. Un dict guarda cuántas veces apareció cada suma prefija.

El dict empieza con {0: 1}, que es p[0]. Así se cuentan los subarreglos que empiezan en la primera posición.

Avanzar paso a paso. En cada posición se busca p − x en el dict y luego se agrega p. Si se agrega antes de buscar, con x = 0 se contaría un subarreglo vacío. Funciona con valores negativos, porque no depende de que la suma crezca.

Solución · CSES 1661 · Subarray Sums II

Contar sumas prefijas anteriores

from collections import defaultdict

def main():
    n, x = map(int, input().split())
    a = list(map(int, input().split()))
    vistas = defaultdict(int)
    vistas[0] = 1
    p = cuenta = 0
    for v in a:
        p += v
        cuenta += vistas[p - x]
        vistas[p] += 1
    print(cuenta)

main()

Una pasada con operaciones de dict en O(1) en promedio: O(n).

No hace falta guardar el arreglo p: basta la suma actual.

Con n = 2·10⁵ tardó 0.05 s (PyPy 3.11, Apple M4).

La respuesta puede llegar a n(n + 1)/2 ≈ 2·10¹⁰, por ejemplo con todos los valores en 0 y x = 0.

Parte 5

Two pointers

Dos índices que solo avanzan, y por eso recorren el arreglo en O(n).

Two pointers

Dos valores que suman x en un arreglo ordenado

Valores ordenados.
i, j = 0, n - 1
while i < j:
    s = a[i] + a[j]
    if s == x:
        break           # encontrados
    if s < x:
        i += 1
    else:
        j -= 1

Si a[i] + a[j] < x, a[i] no suma x con ningún valor que quede, porque a[j] es el mayor. Se descarta a[i]. Si la suma es mayor, se descarta a[j].

Cada vuelta descarta un valor: O(n) después de ordenar.

Probar x = 13 (los dos índices se mueven), x = 17 y x = 21 (no hay solución). Es la misma técnica de Ferris Wheel en la semana 6.

Idea · CSES 1640

Sum of Two Values

Pregunta para el grupo

La técnica de dos índices necesita los valores ordenados, pero la respuesta pide las posiciones originales. ¿Qué se ordena?

Los índices, por su valor: orden = sorted(range(n), key=lambda k: a[k]), como en la semana 6.
i y j recorren orden. Se compara a[orden[i]] + a[orden[j]] con x y se imprimen orden[i] + 1 y orden[j] + 1.

Dejar uno o dos minutos para que el grupo responda. Después avanzar con → para mostrar la idea paso a paso. Otra solución recorre el arreglo con un dict de valor a posición y busca x − aᵢ; también es O(n).

Solución · CSES 1640 · Sum of Two Values

Dos índices sobre los índices ordenados

def main():
    n, x = map(int, input().split())
    a = list(map(int, input().split()))
    orden = sorted(range(n), key=lambda k: a[k])
    i, j = 0, n - 1
    while i < j:
        s = a[orden[i]] + a[orden[j]]
        if s == x:
            print(orden[i] + 1, orden[j] + 1)
            return
        if s < x:
            i += 1
        else:
            j -= 1
    print("IMPOSSIBLE")

main()

O(n log n) por el ordenamiento y O(n) por los dos índices.

Como i < j, las dos posiciones siempre son distintas.

Con n = 2·10⁵ y sin solución (todos los índices se recorren) tardó 0.12 s (PyPy 3.11, Apple M4).

El return dentro de main() termina el programa apenas se imprime la respuesta.

Ventana deslizante

Ventana de tamaño fijo

# mayor suma de k valores seguidos
s = sum(a[:k])
mejor = s
for der in range(k, n):
    s += a[der] - a[der - k]   # entra uno, sale otro
    mejor = max(mejor, s)

Una ventana es un subarreglo a[izq..der]. Al moverla una posición, entra a[der] por la derecha y sale a[der − k] por la izquierda.

Con la suma de la ventana anterior, la nueva cuesta O(1). Recalcular cada ventana con sum cuesta O(k).

Lo mismo sirve para contar letras en una ventana: se suma 1 a la letra que entra y se resta 1 a la que sale.

Ejemplo: a = [4, 2, 7, 1, 3] y k = 2. Las sumas son 6, 9, 8 y 4; la mayor es 9. Recalcular todas con sum cuesta O(n · k).

Ventana deslizante

Ventana de tamaño variable

a = [2, 4, 1, 2, 7] y x = 7. Todos los valores son positivos.

izq = suma = cuenta = 0
for der in range(n):
    suma += a[der]
    while suma > x:
        suma -= a[izq]
        izq += 1
    if suma == x:
        cuenta += 1

der avanza en cada vuelta del for e izq solo avanza dentro del while. Cada uno se mueve a lo sumo n veces, así que el total es O(n).

Por qué se puede achicar sin perder respuestas: con valores positivos, si a[izq..der] ya suma más que x, cualquier ventana que empiece en izq y termine más a la derecha suma todavía más. Con valores negativos esto no se cumple y hace falta la técnica de la parte 4.

Idea · CSES 1141

Playlist

Pregunta para el grupo

La ventana a[izq..der] no tiene repetidos y entra a[der + 1], que ya está en la ventana. ¿Hasta dónde hay que mover izq?

Hasta pasar la copia anterior de esa canción. Se sacan canciones por la izquierda mientras a[der + 1] siga en la ventana.
Un set guarda las canciones de la ventana: preguntar si está, agregar y quitar cuestan O(1). Cada canción entra y sale una vez, así que es O(n).

Dejar uno o dos minutos para que el grupo responda. Después avanzar con → para mostrar la idea paso a paso.

Solución · CSES 1141 · Playlist

Una ventana sin repetidos

def main():
    n = int(input())
    k = list(map(int, input().split()))
    en_ventana = set()
    izq = mejor = 0
    for der in range(n):
        while k[der] in en_ventana:
            en_ventana.remove(k[izq])
            izq += 1
        en_ventana.add(k[der])
        mejor = max(mejor, der - izq + 1)
    print(mejor)

main()

Con n = 2·10⁵ tardó 0.05 s (PyPy 3.11, Apple M4). Otra forma guarda en un dict la última posición de cada canción y salta izq de una vez a esa posición + 1, si está dentro de la ventana.

Resumen

Reglas para rangos

  1. Suma de un rango: p[b] - p[a - 1], con p = list(accumulate(x, initial=0)).
  2. En 2D se resta arriba y a la izquierda, y se suma la esquina.
  3. Sumar u de a a b: d[a] += u y d[b + 1] -= u; al final, sumas prefijas de d.
  4. Contar subarreglos con suma x: un dict con las sumas prefijas vistas, empezando en {0: 1}.
  5. Dos índices que solo avanzan recorren el arreglo en O(n).
  6. La ventana de tamaño variable necesita valores positivos.
