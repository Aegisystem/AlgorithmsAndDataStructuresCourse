Parte 1

Dijkstra

Caminos más cortos cuando las aristas tienen pesos.

Dijkstra

Sacar siempre el nodo más cercano

from heapq import heappush, heappop

INF = float("inf")
dist = [INF] * (n + 1)
dist[s] = 0
h = [(0, s)]
while h:
    d, u = heappop(h)
    if d > dist[u]:
        continue        # copia vieja
    for v, c in adj[u]:
        if d + c < dist[v]:
            dist[v] = d + c
            heappush(h, (dist[v], v))

Avanzar paso a paso desde el nodo 1. Debajo de cada nodo está su distancia actual. El heap guarda (distancia, nodo). Cuando un nodo sale del heap por primera vez, su distancia ya es la definitiva. Los nodos 2, 5 y 6 mejoran su distancia, así que quedan copias viejas en el heap que se saltan al salir.

Dijkstra en Python

Borrado perezoso y costo

BFS cuenta aristas. Con pesos, el camino 1 → 3 → 2 (2 + 3 = 5) es más corto que la arista 1 → 2 (7), aunque usa más aristas.

heapq no permite cambiar la prioridad de un elemento. Cuando un nodo mejora, se mete otra copia con la distancia nueva. Al sacar una copia con d > dist[u], se descarta: es el borrado perezoso.

Cada arista mete a lo sumo una copia, así que el heap tiene O(m) elementos. El total es O((n + m) log m).

Condiciones

  • Los pesos no pueden ser negativos. Con un peso negativo, un nodo que ya salió del heap podría mejorar después, y Dijkstra da una respuesta equivocada.
  • Sirve en grafos dirigidos y no dirigidos.
  • Con todos los pesos iguales, BFS da lo mismo y es más simple.

Los grafos con pesos negativos (Bellman-Ford) quedan fuera del programa. Sin el if d > dist[u]: continue el resultado sigue siendo correcto, pero un nodo se puede procesar varias veces y el programa puede dar TLE.

Solución · CSES 1671 · Shortest Routes I

Dijkstra desde la ciudad 1

from heapq import heappush, heappop

def main():
    n, m = map(int, input().split())
    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        a, b, c = map(int, input().split())
        adj[a].append((b, c))
    INF = float("inf")
    dist = [INF] * (n + 1)
    dist[1] = 0
    h = [(0, 1)]
    while h:
        d, u = heappop(h)
        if d > dist[u]:
            continue
        for v, c in adj[u]:
            if d + c < dist[v]:
                dist[v] = d + c
                heappush(h, (dist[v], v))
    print(" ".join(map(str, dist[1:])))

main()

O((n + m) log m).

Con n = 10⁵ y m = 2·10⁵ tardó 0.17 s (PyPy 3.11, Apple M4).

Todas las ciudades se alcanzan, así que ningún valor queda en inf.

Parte 2

Orden topológico

Ordenar tareas que dependen unas de otras.

Algoritmo de Kahn

Primero los nodos sin requisitos pendientes

entran = [0] * (n + 1)
for a, b in aristas:      # a antes que b
    entran[b] += 1
cola = deque(u for u in range(1, n + 1)
             if entran[u] == 0)
orden = []
while cola:
    u = cola.popleft()
    orden.append(u)
    for v in adj[u]:
        entran[v] -= 1
        if entran[v] == 0:
            cola.append(v)
# len(orden) < n: hay un ciclo

Un orden topológico pone cada nodo antes de todos sus sucesores. Solo existe si el grafo dirigido no tiene ciclos. Debajo de cada nodo está cuántas aristas le faltan por quitar. Con el grafo "con ciclo", los nodos 3, 5 y 6 nunca llegan a 0 y quedan fuera del orden: así se detecta un ciclo dirigido. Es O(n + m).

Solución · CSES 1679 · Course Schedule

Kahn con una cola

from collections import deque

def main():
    n, m = map(int, input().split())
    adj = [[] for _ in range(n + 1)]
    entran = [0] * (n + 1)
    for _ in range(m):
        a, b = map(int, input().split())
        adj[a].append(b)
        entran[b] += 1
    cola = deque(u for u in range(1, n + 1) if entran[u] == 0)
    orden = []
    while cola:
        u = cola.popleft()
        orden.append(u)
        for v in adj[u]:
            entran[v] -= 1
            if entran[v] == 0:
                cola.append(v)
    if len(orden) < n:
        print("IMPOSSIBLE")
    else:
        print(" ".join(map(str, orden)))

main()

O(n + m).

Con n = 10⁵ y m = 2·10⁵ tardó 0.10 s (PyPy 3.11, Apple M4).

Con una pila en lugar de una cola también sale un orden válido.

Parte 3

Union-Find

Unir conjuntos y preguntar si dos elementos están en el mismo.

Union-Find

Cada conjunto es un árbol con una raíz

padre
tam

Cada nodo apunta a su padre y la raíz se apunta a sí misma. Dos nodos están en el mismo conjunto si tienen la misma raíz.

Unión por tamaño: la raíz del árbol pequeño cuelga de la del grande. Así ningún árbol pasa de log n niveles.

Compresión de caminos: al buscar la raíz de x, todos los nodos del camino pasan a apuntar directo a la raíz.

Avanzar paso a paso. Las flechas van de cada nodo a su padre. En unir(4, 8) se busca la raíz de 4: el camino es 4 → 3 → 1, y la compresión deja 4 → 1. Con las dos mejoras, cada operación cuesta casi O(1) en promedio.

Union-Find en Python

Raíz iterativa y unión por tamaño

padre = list(range(n + 1))
tam = [1] * (n + 1)

def raiz(x):
    r = x
    while padre[r] != r:
        r = padre[r]
    while x != r:         # compresión
        sig = padre[x]
        padre[x] = r
        x = sig
    return r

def unir(a, b):
    a, b = raiz(a), raiz(b)
    if a == b:
        return False      # ya estaban juntos
    if tam[a] < tam[b]:
        a, b = b, a
    padre[b] = a
    tam[a] += tam[b]
    return True

raiz hace dos pasadas: la primera encuentra la raíz y la segunda hace que cada nodo del camino apunte a ella.

Es iterativa. La versión recursiva de la compresión es más corta, pero antes de la primera compresión un camino puede ser largo.

unir devuelve si unió dos conjuntos distintos. tam solo es correcto en las raíces.

Union-Find no permite separar conjuntos ni recorrer sus elementos: solo unir y preguntar. Para esas dos operaciones es mucho más rápido que volver a hacer un DFS cada vez.

Parte 4

Kruskal

Conectar todos los nodos con el menor costo total.

Árbol de expansión mínima

Las aristas de la más barata a la más cara

aristas.sort()          # (costo, a, b)
costo = usadas = 0
for c, a, b in aristas:
    if unir(a, b):
        costo += c
        usadas += 1
# usadas == n - 1: el grafo es conexo

Un árbol de expansión mínima conecta los n nodos con n − 1 aristas y la menor suma de costos.

Kruskal toma cada arista en orden de costo y la acepta si une dos componentes distintas. Es un greedy (semana 10) que usa Union-Find.

Avanzar paso a paso con el grafo del ejemplo de Road Reparation. En verde, aceptada; en rojo, rechazada porque formaría un ciclo. Ordenar cuesta O(m log m) y las uniones casi O(1), así que el total es O(m log m).

Idea · CSES 1669

Round Trip

Pregunta para el grupo

En un DFS, ¿qué arista indica que hay un ciclo?

Una arista desde u hacia un nodo v que sigue en la pila del DFS (un ancestro de u) y que no es el padre de u.
El ciclo es v, u, padre[u], …, hasta volver a v. Hace falta un DFS de verdad, que baje por un vecino antes de mirar el siguiente: cada nodo guarda cuál es el próximo vecino por revisar.

Dejar uno o dos minutos para que el grupo responda. Después avanzar con → para mostrar la idea paso a paso. El DFS de la semana 12, que marca al meter en la pila, no sirve aquí: un nodo marcado no siempre es un ancestro. Union-Find también detecta que hay un ciclo, pero no da el recorrido.

Solución · CSES 1669 · Round Trip

DFS iterativo con estados

def main():
    n, m = map(int, input().split())
    adj = [[] for _ in range(n + 1)]
    for _ in range(m):
        a, b = map(int, input().split())
        adj[a].append(b)
        adj[b].append(a)
    padre = [0] * (n + 1)
    estado = [0] * (n + 1)  # 0, 1 en pila, 2 listo
    sig = [0] * (n + 1)     # próximo vecino
    for s in range(1, n + 1):
        if estado[s]:
            continue
        estado[s] = 1
        pila = [s]
        while pila:
            u = pila[-1]
            if sig[u] == len(adj[u]):
                estado[u] = 2
                pila.pop()
                continue
            v = adj[u][sig[u]]
            sig[u] += 1
            if v == padre[u]:
                continue
            if estado[v] == 1:
                ciclo = [v]
                x = u
                while x != v:
                    ciclo.append(x)
                    x = padre[x]
                ciclo.append(v)
                print(len(ciclo))
                print(" ".join(map(str, ciclo)))
                return
            if estado[v] == 0:
                estado[v] = 1
                padre[v] = u
                pila.append(v)
    print("IMPOSSIBLE")

main()

O(n + m). Con 10⁵ ciudades en un solo ciclo (la pila llega a 10⁵ nodos) tardó 0.06 s (PyPy 3.11, Apple M4). Como no hay carreteras repetidas, saltar al padre basta para no contar a → b → a.

Resumen

Reglas para grafos con pesos y dependencias

  1. Dijkstra: heap de (distancia, nodo) y saltar las copias con d > dist[u]. Pesos no negativos.
  2. Orden topológico: Kahn con los nodos sin aristas de entrada pendientes.
  3. Si Kahn deja nodos fuera, el grafo dirigido tiene un ciclo.
  4. Union-Find: raíz iterativa con compresión y unión por tamaño.
  5. Kruskal: aristas por costo; aceptar las que unen componentes distintas.
  6. Ciclo en un grafo no dirigido: DFS con estados y una arista a un ancestro que no es el padre.
